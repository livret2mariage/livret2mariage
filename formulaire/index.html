A5 est le format le plus courant pour un livret de messe — plus compact, plus économique à imprimer, et facile à tenir en main pendant la célébration.

« PDF uniquement » : à imprimer vous-même. « PDF + impression » : nous imprimons pour vous.

Les chants (facultatif)

Si vous ne les connaissez pas encore, laissez ces champs vides — vous pourrez les ajouter plus tard, ou laisser la chorale s'en charger. Vous pouvez aussi coller les paroles si vous voulez qu'elles apparaissent dans le livret.

Les paroles de chants restent souvent protégées par des droits d'auteur — assurez-vous d'avoir le droit de les reproduire avant de les coller ici (un usage privé pour quelques exemplaires, comme un mariage, est en général peu à risque).
